# Winestro 🔄 Listmonk

Sync your [Winestro](https://www.winestro.cloud/) subscribers to [Listmonk](https://listmonk.app/).

## Requirements

```bash
brew install sqlc
```

```bash
sqlc generate
```

## Run

```bash
docker compose up -d demo-db
```

```bash
docker compose up -d demo-app
```

```bash
docker compose up -d winmonk
```
